Garbage Collection Management System

HTML CSS JavaScript
Problem
Residents had no simple way to request a collection or know when their zone would be served, and admins had no single view of requests.
Solution
A web platform with resident request forms, zone-based pickup scheduling and an admin dashboard to track and manage requests.
Result
A working, deployed system covering the full request-to-schedule flow for two user roles (resident and admin). Also my final-year project.
Live demo GitHub repo

Property Listings Website

HTML CSS JavaScript Responsive
Problem
Property buyers need to compare listings quickly, and many real estate sites bury filters and make enquiring hard on mobile.
Solution
A mobile-first listings site with filters, an image gallery and clear enquiry prompts on every listing, with animated sections for a modern feel.
Result
A fully responsive site, live on GitHub Pages, that works from phone to desktop without layout breaks.
Live demo GitHub repo

Farm and Orchard Management System

React JavaScript CSS
Problem
Farm teams track crops, stock and harvests across notebooks and spreadsheets, which makes planning and handovers error-prone.
Solution
A React app for crop scheduling, inventory and harvest tracking, with separate dashboards for each user role.
Result
One place to plan, record and review farm activity, built as a component-based app and deployed live.
Live demo GitHub repo
